# Dynamics Zentrum — UK's Trusted Microsoft Dynamics 365 Partner

A modern, high-performance enterprise consulting website rebuilt with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**.

![Dynamics Zentrum Preview](/public/assets/dz-logo.png)

---

## 🚀 Key Features & Highlights

- **Custom Design System**:
  - Exact neo-fintech enterprise palette: Electric Magenta (`#cc00e6`), Deep Midnight Aubergine/Navy (`#14031a`), Lilac Glow (`#f5a8ff`), and Vibrant Purple (`#7c3aed`).
  - Seamless **Dark / Light Mode** switching with persistent theme preference.
  - Custom glassmorphism, animated glow orbs, and button shine (`.btn-shine`) effects.
- **Enterprise Navigation & Mega Menus**:
  - Sticky glassmorphic navbar with dynamic backdrop blur.
  - 2-Column interactive mega dropdowns for **Services**, **Solutions**, and **Industries**.
  - Quick Search modal searching across all practices in real time.
  - Mobile-responsive sliding drawer with theme switch and quick booking CTA.
- **Hero Section**:
  - Concentric rotating SVG orbital rings with floating isometric `d365-3d.png` graphic.
  - 4 floating glass badges for Copilot AI, Power Platform, Fabric, and Supply Chain.
  - Micro-animated Microsoft Partner verification badge with radar ping.
- **Interactive Delivery Console**:
  - Live simulation of an enterprise rollout with real-time sprint status and progress bars across 5 phases (Fit-Gap, Design, Build, UAT, Hypercare).
- **Interactive ROI / TCO Financial Calculator**:
  - Dynamic dual-colored sliders for Users (25 - 2,000), Annual Turnover (£5M - £250M), Hours Saved/week, and Hourly Rates.
  - Real-time calculations for Net Annual Benefit, Projected ROI %, Payback Period (months), and 3-Year Value Creation.
  - Live visual breakdown bar for Productivity Gain, Revenue Uplift, and Efficiency Savings.
- **Complete Domain Coverage**:
  - 16 Regulated Industries with custom monospace indexing (`01` to `16`).
  - 13 Microsoft Solutions (Business Central, Finance, Supply Chain, Sales, etc.).
  - 8 Consulting Lifecycle Services (Strategic Consulting, Implementation, Migration, Upgrades, Support, etc.).
  - Detailed dedicated subpages with full architecture blueprints for each solution and service.
- **Enterprise 5-Column Footer**:
  - Microsoft Partner accreditation badges.
  - Giant 180px SVG text watermark (`DYNAMICS`) with vertical linear gradient fade.

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Routing:** [React Router v7](https://reactrouter.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Google Fonts (`Sora`, `Inter`, `Manrope`)

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/umairfida643-droid/Dynamics-Zentrum.git

# 2. Enter project directory
cd Dynamics-Zentrum

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the site locally.

### Production Build
```bash
npm run build
```
Generates optimized static production assets in the `dist/` folder.
